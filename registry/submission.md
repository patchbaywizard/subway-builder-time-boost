time-boost

### Display Name

Time Boost

### Description

Five extra simulation speed levels beyond Subway Builder's native ultrafast, with a live **Actual hr/s** readout showing measured game hours per real second.

![Time Boost icon](https://raw.githubusercontent.com/patchbaywizard/subway-builder-time-boost/v1.8.1/time-boost/images/icon.png)

Click **Boost 1–5**, or use **[ / ]** to step up and down through the extra levels. **Reset** restores the original ultrafast settings. Selecting a speed preserves pause.

Higher levels request more simulation work but are not guaranteed to run faster. Compare the actual readout to find the best level for your city and computer.

Developed against Subway Builder 1.7.1 and observed in gameplay on macOS. Windows and Linux are untested. Code developed with AI assistance; icon AI-generated. Developed and maintained by [patchbaywizard](https://github.com/patchbaywizard).

**Upgrading from the original GitHub release:** replace the old folder and re-enable Time Boost in Settings → Mods. Version 1.8.0 changes the mod ID to match this registry listing. Do not keep both copies installed.
